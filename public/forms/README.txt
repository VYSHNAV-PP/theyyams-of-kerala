Form pictures go here.

Name each file after the Theyyam form, lower case, words joined by dashes, .jpg:

  muchilottu-bhagavathi.jpg
  raktha-chamundi.jpg
  vishnumoorthi.jpg
  pottan-theyyam.jpg
  kandanar-kelan.jpg
  gulikan.jpg
  ...

Landscape or square images work best (they are cropped to 4:3). Until a file exists,
the card shows a placeholder with the Malayalam name.
